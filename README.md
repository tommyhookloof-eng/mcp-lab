# MCP Lab\n\nA clean Python FastMCP practice environment designed for GitHub Codespaces. The server runs in the cloud, so the iPhone only needs a browser.\n\n## Launch in one click\n\n[Open this repository in GitHub Codespaces](https://codespaces.new/tommyhookloof-eng/mcp-lab?quickstart=1)\n\nChoose a Codespaces machine when prompted. The dev container installs the dependencies automatically.\n\n## Run the smoke test\n\n```bash\npython test_server.py\n```\n\n## Run the server\n\n```bash\npython server.py\n```\n\nThe server listens on port 8000. In Codespaces, open the Ports panel and use the forwarded URL.\n\nThe starter app includes calculation tools, Adeoti note resources, and prompts.\n
